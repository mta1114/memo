# Mémo – Fransızca

Fransızca kelime kartları (aralıklı tekrar / FSRS) ve "Dinle ve Anla" alıştırmaları.
İnternetsiz çalışan bir web uygulamasıdır (PWA). iPad ve Android'de ana ekrana eklenir.

## İçerik
- **Desteler:** Temel A1–A2 (sözlük, çalışmaya kapalı başlar), B1 (282), B2 (251), Kimya (204)
- **20 dinleme metni:** 7 B1, 7 B2, 6 kimya. Her metinde 5 çoktan seçmeli soru, 5 açık uçlu soru ve 9–13 boşluk var.

## Yeni içerik ekleme
Uygulamadaki **📋 Yeni paket isteği** butonuyla mesajı kopyala, Claude'a yapıştır.
Claude'un hazırladığı `.txt` dosyasını **📥 Dosyadan ekle** ile yükle.
Dosya biçimleri uygulamada **Ayarlar → Yardım** bölümünde anlatılıyor.

## GitHub Pages ile yayınlama
1. Bu klasördeki dosyaları bir GitHub deposuna yükle (`index.html` deponun kök dizininde olmalı).
2. Depoda **Settings → Pages → Build and deployment → Source: Deploy from a branch**, Branch: `main`, klasör: `/ (root)` → **Save**.
3. 1–2 dakika sonra adres hazır olur: `https://KULLANICI-ADIN.github.io/DEPO-ADI/`

## Telefona/tablete kurma
- **iPad (Safari):** adresi aç → Paylaş → **Ana Ekrana Ekle**
- **Android (Chrome):** adresi aç → ⋮ menüsü → **Uygulamayı yükle** / Ana ekrana ekle

Veriler cihazda saklanır; Ayarlar → **Yedek dosyası indir** ile yedek al, diğer cihazda **Yedekten geri yükle**.
